## 1. 背景與目標

### 1.1 專案背景
DUPR（Dynamic Universal Pickleball Rating）是匹克球/Padel 選手的評分系統，官方網站與 App 僅支援「一次查一位選手」的介面。當使用者需要幫一整批球員（例如一場比賽的所有報名者、一個球隊名單）確認 DUPR 分數時，得逐一手動搜尋、複製、貼到 Excel，非常耗時。

DUPR 目前沒有公開的「批次查詢」API，但官方有登入後可用的查詢端點（`search players`、`get player`），可以用程式化方式逐筆呼叫、再彙整結果。本專案希望做一個網頁小工具，讓使用者一次貼上多個名字或 DUPR ID，自動幫忙查完所有分數並整理成表格。

### 1.2 目標
- 業務目標：把「批次核對選手 DUPR 分數」這件事從手動查詢（每人約 1-2 分鐘）縮短為一次貼上、幾秒到幾十秒內取得所有結果。
- 使用者目標：貼上一份名單（名字或 ID），拿到一張整理好、可匯出的分數對照表。
- 成功指標（KPI）：⚠️ 待補充（例如：單次查詢 20 筆名單於 30 秒內完成、查詢成功率 > 90%）。

## 2. 使用者與情境

### 2.1 目標使用者
- 主要使用者：專案擁有者本人（Charles），用於個人或小型球隊/賽事管理需求。
- 次要使用者：⚠️ 待確認——是否會開放給其他人（例如球隊隊友、賽事主辦方）使用，這會影響部署方式與帳號授權設計（詳見第 7 節）。

### 2.2 使用者情境 / User Story
> As a 賽事或球隊管理者, I want to 一次貼上多個球員的名字或 DUPR ID, so that 我可以快速拿到所有人的 DUPR 分數，不用一個一個手動查。

補充情境：
> As a 使用者, I want to 用名字查詢時看到「同名多人」的候選清單並自己選對的人, so that 不會抓錯分數。

> As a 使用者, I want to 把查詢結果匯出成 CSV, so that 我可以直接用在自己的 Excel 名單裡。

## 3. 功能範圍

### 3.1 In Scope（本次包含）
| 功能項目 | 說明 | 優先級 |
|---|---|---|
| 批次輸入 | 使用者可貼上多行名字/ID，或上傳簡單 CSV | P0 |
| 批次查詢 | 後端逐筆呼叫 DUPR API 查詢分數，前端顯示整體進度 | P0 |
| 結果表格 | 顯示輸入的名字/ID、比對到的 DUPR 檔案、雙打/單打分數 | P0 |
| 同名多筆比對 | 用名字查詢若有多個候選人，列出候選清單供使用者選擇 | P0 |
| 錯誤/查無結果標示 | 查不到或 API 失敗時，在該筆標示原因 | P0 |
| CSV 匯出 | 將結果表格匯出成 CSV 檔 | P1 |
| 查詢結果快取 | 短期內重複查詢同一人不重打 API | P1 |
| 多人共用登入 | 支援多個使用者各自用自己的 DUPR 帳號登入 | P2（視第 7 節開放問題而定） |

### 3.2 Out of Scope（本次不包含）
- 修改/寫入 DUPR 上的資料（本工具僅供查詢，不做任何寫入操作）。
- 歷史戰績、對戰紀錄等進階數據分析（僅抓取當前分數）。
- 行動 App（僅網頁）。

## 4. 功能需求概述

1. **批次輸入介面**：提供一個文字框（一行一筆，可為名字或 DUPR ID 混合輸入），或提供 CSV 上傳；使用者送出後開始查詢。
2. **查詢執行與進度顯示**：前端顯示「查詢中 X / N」的進度，避免使用者誤以為當機（因為要逐筆呼叫外部 API，無法瞬間完成）。
3. **結果呈現**：以表格呈現「輸入內容 → 比對到的球員 → 分數（雙打/單打）→ 狀態（成功/查無/多筆待選/失敗）」。
4. **多筆候選處理**：當用名字查到多位同名球員時，該筆先標示「待選擇」，使用者可展開候選清單（含所在地區等輔助資訊）手動確認。
5. **匯出**：一鍵將目前表格內容匯出成 CSV。

## 5. 非功能需求

| 類別 | 需求說明 |
|---|---|
| 效能 | 查詢採並發限流方式呼叫 DUPR API（例如同時最多 3-5 筆），避免觸發官方速率限制；⚠️ 待補充實際可接受的批次上限（例如單次 50 筆） |
| 安全性 | DUPR 登入憑證（帳號密碼或 bearer token）僅存於伺服器端環境變數，不可暴露於前端或版本控制；查詢結果不落地成公開資料 |
| 相容性 | 支援現代桌面瀏覽器（Chrome/Edge/Safari 最新版即可，不特別要求支援舊版或行動裝置版面） |
| 可用性 | 單人或小團隊使用即可，不要求高可用性（無需 SLA） |

## 6. UI/UX 說明

頁面流程（單頁應用）：
1. 首頁：一個輸入框（可貼多行文字）＋「上傳 CSV」按鈕 ＋「開始查詢」按鈕。
2. 查詢中：顯示進度條與目前處理到第幾筆。
3. 結果頁（同頁下方呈現）：表格顯示所有結果；「多筆待選」的列可展開选择；提供「匯出 CSV」按鈕。

Wireframe：⚠️ 待補充（目前僅有文字流程說明，尚無設計稿）。

## 7. 相依性與限制

- 相依系統：DUPR 官方 API（`events.mydupr.com` / `backend.mydupr.com`），需要有效的 DUPR 帳號登入取得 bearer token。
- 技術限制：
  - DUPR 沒有官方「批次查詢」端點，必須逐筆呼叫再彙整，效能受限於官方 API 的回應速度與速率限制（實際限制未知）。
  - DUPR 服務條款是否允許此類自動化查詢方式尚未正式確認，建議先以個人/小範圍使用為主，避免公開對外開放造成帳號或服務風險。
- 時程限制：⚠️ 待補充。
